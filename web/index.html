怎麼跑起來

這頁要用小型伺服器開（file:// 不能 fetch）：專案根目錄跑 python -m http.server 8000，開 http://localhost:8000/web/

1. 算轉動表：python ml/gen_moves.py

2. 算 2×2×2 的正確答案：python ml/bfs.py

3. 訓練：python ml/train.py --size 2

4. 匯出給網頁：python ml/export_policy.py --size 2

5. 大樣本實測：python ml/benchmark.py --size 2 --n 1000
